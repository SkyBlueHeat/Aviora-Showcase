MIGRATION GUIDE

When updating to a new version:

1. Download the new version from Etsy
2. Open both old and new files
3. Copy your data from the old file
4. Paste into the new file
5. Save the new version
6. Archive the old version

TIPS:
- Always keep a backup before migrating
- Verify formulas after migration
- Check that all data transferred correctly
- Test Dashboard calculations
