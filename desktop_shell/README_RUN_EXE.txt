JobTracker PRO — Desktop Application (Phase 1.7)
================================================

Thank you for downloading JobTracker PRO!

This is a desktop application that runs on Windows without needing
to install anything. Just double-click and it opens.


QUICK START
-----------
1. Double-click JobTrackerPRO.exe

2. The app window opens automatically — no browser needed

3. Use the sidebar on the left to switch between pages:
   - Dashboard: Overview of your job search
   - Application Kit: Manage your applications
   - Cover Letter Studio: Write cover letters
   - LinkedIn Composer: Create LinkedIn posts
   - Interview Prep: Practice interview questions
   - Salary Calculator: Calculate salary packages

4. Click the X button to close the app


SYSTEM REQUIREMENTS
-------------------
- Windows 10 or 11 (64-bit)
- Microsoft Edge WebView2 Runtime
  (This is already installed on most Windows 10/11 computers.
  If the app doesn't open, download it free from:
  https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
- No internet connection required
- No Python, Node.js, or other software needed

TROUBLESHOOTING
---------------
Problem: The app doesn't open when I double-click it.
Solution: Make sure you have WebView2 Runtime installed.
          Download from: https://developer.microsoft.com/en-us/microsoft-edge/webview2/

Problem: Windows shows a "Windows protected your PC" warning.
Solution: Click "More info" then "Run anyway". This happens because
          the app doesn't have a publisher certificate yet.

Problem: The app opens but looks plain/unstyled.
Solution: This shouldn't happen, but if it does, make sure your
          Windows is up to date with the latest WebView2 version.
