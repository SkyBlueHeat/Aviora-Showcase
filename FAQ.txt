FEATURES & FUNCTIONALITY

Q: How does the Dashboard update automatically?
A: The Dashboard uses formulas that pull data from the other sheets. When you add or update information in the Applications, Interview Tracker, or other sheets, the Dashboard reflects those changes instantly.

Q: What KPIs does the Dashboard track?
A: The Dashboard tracks: Applications Sent, Interviews, Offers, Rejections, Ghosted, Response Rate, Interview Rate, Offer Rate, Average Salary, Highest Offer, Applications This Week, Applications This Month, and more.

Q: Can I add my own columns to the sheets?
A: Yes, you can insert new columns. However, be careful not to delete or rename existing columns that are referenced by Dashboard formulas.

Q: How do the dropdown menus work?
A: Dropdown menus are pre-configured in specific cells. Click on the cell and select an option from the list. This ensures consistent data entry.

Q: What is the Fit Score?
A: The Fit Score is a 1-100 rating you assign to each application based on how well you match the job requirements. Use it to prioritize your applications.

Q: How does the Salary Comparison tool work?
A: Enter the details of each offer (base salary, bonus, equity, benefits, etc.). The Total Compensation column automatically calculates the sum, and you can compare offers side-by-side.

Q: Can I track multiple job searches?
A: Yes, you can use the tracker for multiple job searches. You might want to create separate copies of the file for different job types or time periods.

Q: Does the tracker sync across devices?
A: The Excel file itself doesn't sync. However, if you save it to Google Drive or use Google Sheets, it will sync across devices.

Q: How do I print the tracker?
A: You can print any sheet by going to File > Print. Adjust the print settings to fit your needs. The tracker is designed to be print-friendly.

PYTHON LAUNCHER & TOOLS

Q: What is the Python launcher?
A: The launcher is a desktop app that opens from `launcher.py`. It provides a visual interface for tools like ATS Resume Checker, Job Description Analyzer, Interview Prep, LinkedIn Message Generator, Salary Calculator, and Streak Tracker.

Q: Do I need to install Python to use the launcher?
A: Yes, Python 3.9 or higher is required. You also need to install dependencies once by running `pip install -r requirements.txt` in your terminal.

Q: Can I use the Excel tracker without the Python tools?
A: Yes, the Excel tracker works completely on its own. The Python tools are optional enhancements.

Q: How do I run the launcher?
A: Double-click `launcher.py`, or open a terminal in the product folder and run `python launcher.py`.

Q: What is the ATS Resume Checker?
A: It analyzes your resume against a job description and gives you an ATS compatibility score (0-100), missing keywords, weak verbs, and formatting issues.

Q: What file formats work with the ATS Resume Checker?
A: `.docx`, `.pdf`, and `.txt` files are supported.

Q: What is the Job Description Analyzer?
A: It reads any job posting and extracts seniority level, estimated salary range, required skills, red/green flags, and personalized cover letter keywords. It can also add the role to your Excel tracker.

Q: Does the Job Description Analyzer need an internet connection?
A: No, all analysis is done locally on your computer. No API keys are required for basic use.

Q: Can I sync my data with Notion?
A: Yes, the launcher includes a Notion Sync tab. You need a Notion integration token and database ID to use it.

Q: How do I get a Notion token?
A: Go to notion.so → Settings & members → Integrations → New integration. Copy the token and paste it into the launcher’s Notion Sync tab along with your database ID.

Q: Does the email reminder need my email password?
A: Yes, if you want automated follow-up emails, the launcher asks for your SMTP settings (email, password, server, port). This is stored only on your computer and is never sent to us.
