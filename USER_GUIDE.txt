1. INTRODUCTION

The Developer Job Application Tracker PRO is a comprehensive Excel-based tool designed specifically for software developers and IT professionals to manage their job search efficiently.

KEY BENEFITS:
- Organize all job applications in one place
- Track interview progress across multiple stages
- Manage recruiter relationships
- Compare job offers side-by-side
- Analyze job search performance with data
- Never miss a follow-up deadline
- Prioritize applications based on fit score

DESIGN PHILOSOPHY:
Built with an Apple-inspired minimalist aesthetic, this tracker combines professional design with powerful functionality. Every element is crafted to help you navigate your job search with clarity and confidence.

3. SHEET-BY-SHEET GUIDE

===========================================
DASHBOARD
===========================================

PURPOSE:
The Dashboard is your command center. It provides a real-time overview of your entire job search with automatic KPI calculations and visual metrics.

SECTIONS:

KPI CARDS (Top Row):
- Applications Sent: Total number of applications submitted
- Interviews: Number of interviews scheduled or completed
- Offers: Number of job offers received
- Rejections: Number of rejections received

KPI CARDS (Second Row):
- Response Rate: Percentage of applications that received a response
- Interview Rate: Percentage of applications that led to interviews
- Offer Rate: Percentage of applications that resulted in offers
- Ghosted: Number of applications with no response

SALARY KPIs:
- Average Salary: Average of all salary entries
- Highest Offer: Maximum salary offer received
- Applications This Week: Applications submitted in the last 7 days
- Applications This Month: Applications submitted this calendar month

JOB PIPELINE TABLE:
Shows the breakdown of applications by status:
- Applied: Initial applications submitted
- Screening: In recruiter screening phase
- Interview: In interview process
- Offer: Offers received
- Rejected: Rejections received
- Ghosted: No response

Each row shows:
- Status: Current application status
- Count: Number of applications in that status
- Percentage: Percentage of total applications

RECENT ACTIVITY:
Displays the 5 most recently added applications with:
- Company name
- Current status
- Date applied

UPCOMING FOLLOW-UPS:
Shows applications with upcoming follow-up dates:
- Company name
- Follow-up date
- Priority level

PRIORITY JOBS:
Displays top applications by Fit Score:
- Company name
- Role
- Fit Score

HOW IT WORKS:
The Dashboard uses formulas that automatically pull data from other sheets. When you add or update information in the Applications sheet, the Dashboard updates instantly.

APPLICATIONS
===========================================

PURPOSE:
Track every job application in detail with comprehensive data points.

COLUMNS:

Company:
- Name of the company you applied to
- Use the official company name

Role:
- Job title as listed in the posting
- Include seniority level (e.g., Senior Frontend Developer)

Location:
- City, State, or Country
- Include "Remote" if fully remote

Remote:
- Dropdown: Yes, No, Hybrid
- Select based on job posting

Salary:
- Expected salary range or offered amount
- Format: $100,000 or $80,000 - $120,000

Source:
- Dropdown: LinkedIn, Indeed, Company Site, Referral, Angel List, Other
- Where you found the job posting

Date Applied:
- Date you submitted the application
- Format: YYYY-MM-DD for consistency

Status:
- Dropdown: Applied, Screening, Interview, Offer, Rejected, Ghosted
- Update as your application progresses

Priority:
- Dropdown: High, Medium, Low
- Based on your interest level and company fit

Fit Score:
- 1-100 rating
- Higher score = better match
- Consider: skills match, location, salary, culture, growth

Follow-up Date:
- Date to follow up if no response
- Typically 1-2 weeks after application

Recruiter:
- Recruiter name if applicable
- Include contact info in Recruiter CRM sheet

Interview Date:
- Scheduled interview date
- Update as interviews are scheduled

Offer:
- Offer details if received
- Link to Salary Comparison sheet for detailed analysis

Notes:
- Any additional information
- Application details, contacts, observations

BEST PRACTICES:
- Fill in as many fields as possible
- Update status regularly
- Use consistent date format
- Add notes for important details
- Link to Recruiter CRM when applicable

SALARY COMPARISON
===========================================

PURPOSE:
Compare job offers side-by-side to make informed decisions about total compensation.

COLUMNS:

Company:
- Company name
- Should match Applications sheet

Base Salary:
- Annual base salary
- Enter as number (e.g., 150000)

Bonus:
- Annual bonus amount
- Enter as number (e.g., 20000)

Equity:
- Equity value (vested per year)
- Enter as number (e.g., 50000)

Benefits:
- Brief description of benefits
- e.g., "Full Health, 401k Match"

PTO:
- Paid time off days
- e.g., "20 days" or "4 weeks"

Remote:
- Dropdown: Yes, No, Hybrid
- Remote work policy

Visa Sponsorship:
- Dropdown: Yes, No, Maybe
- If applicable to your situation

Total Compensation:
- Automatically calculated
- Formula: Base + Bonus + Equity
- Updates as you enter values

Decision Score:
- Your subjective rating
- 1-100 based on overall fit
- Consider salary, benefits, culture, growth

HOW TO USE:
1. Add each offer as a row
2. Enter all compensation details
3. Review Total Compensation automatically
4. Compare benefits and perks
5. Assign Decision Score
6. Use for final decision making

6. TROUBLEBROUBLESHOOTING

FORMULAS NOT CALCULATING:
- Check calculation mode: Formulas > Calculation Options > Automatic
- Ensure no circular references
- Verify cell references are correct
- Check for #REF! errors (deleted cells)

DROPDOWNS NOT WORKING:
- Ensure data validation is enabled
- Check that you're clicking in the correct cell
- Verify the cell range is correct
- Try re-saving the file

FILE WON'T OPEN:
- Check file isn't corrupted
- Try opening in different software
- Ensure you have compatible software
- Re-download from Etsy if needed

FORMATTING ISSUES:
- Some formatting may differ between Excel/Google Sheets/Numbers
- Core functionality remains the same
- Adjust column widths if needed
- Reset zoom to 100%

DATA LOSS:
- Always keep backups
- Use auto-save features
- Save to cloud storage
- Keep original as template

9. PYTHON LAUNCHER TOOLS (v3.0)

===========================================

The Python launcher adds powerful automation tools to your tracker. To use it, make sure Python 3.9+ is installed and run `pip install -r requirements.txt` once.

LAUNCHER HOME
- View live stats from your Excel tracker
- Open the Excel file or project folder with one click
- Stats refresh automatically every 15 seconds

ATS RESUME CHECKER
- Upload a resume in DOCX, PDF, or TXT format
- Optionally provide a job description for targeted analysis
- Get an ATS score, missing keywords, weak verbs, and formatting warnings

JOB DESCRIPTION ANALYZER
- Paste a job description to analyze seniority, salary, skills, and red/green flags
- Add your own skills to receive a personalized fit score
- Cover letter keyword suggestions help you tailor applications
- The role can be added automatically to your Excel tracker

INTERVIEW PREP
- Practice with AI-generated questions across categories
- Receive instant feedback on STAR structure, keywords, and clarity
- Track your progress over time

LINKEDIN MESSAGE GENERATOR
- Generate cold connect, referral, follow-up, thank-you, and reconnection messages
- Customize with your name, target role, company, and recipient

SALARY NEGOTIATION CALCULATOR
- Break down total compensation including base, bonus, equity, and benefits
- Calculate counter-offer strategies
- Compare up to 3 offers side-by-side

GOALS & STREAK TRACKER
- Set daily and weekly application goals
- Log completed applications and maintain a streak
- View weekly summaries and motivational messages

NOTION SYNC
- Sync your Applications sheet to a Notion database
- Requires a Notion integration token and database ID

AUTO BACKUP
- Create timestamped backups of your Excel tracker
- Keeps a configurable number of recent backups
- Optionally sync to cloud folders

DATA EXPORT
- Export any sheet to CSV, JSON, HTML, or PDF
- Useful for sharing or archiving

DATA VALIDATION
- Check your tracker for missing fields, invalid dates, and inconsistent statuses
- Generates a validation report
